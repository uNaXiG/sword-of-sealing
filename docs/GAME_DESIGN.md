# Game Design

本文件只記錄已確認設計與已規劃方向。標示為「規劃中／未定稿」的內容不得視為已核准實作。

## 確認：遊戲定位

- 名稱：Sword of Sealing（封印之劍）。
- 類型：單人 Tactical RPG / SRPG。
- 平台：Web／PWA。
- 核心：3D、Orthographic Camera、格子回合制戰棋。
- 美術：日系異世界輕小說與古典歐洲中世紀奇幻。

## 確認：已實作核心玩法

- 8 × 8 戰場。
- 多角色選取、地形成本、障礙與佔位。
- 移動路徑預覽、動畫、取消與撤銷。
- COMMAND / MOVE / ATTACK 與待命。
- 四種攻擊模式、單目標普通攻擊、HP／傷害。
- 六種基礎職業資料。

## 規劃中：未來系統

- 回合切換與敵方 AI。
- 多角色完整行動限制。
- 技能、裝備、經驗值、等級與成長。
- 戰鬥勝負與關卡。
- 劇情、對話、人物 CG、分支與結局。
- 存檔、PWA、離線與正式發布。

## 確認：世界觀與主角

- 主角具有魔族與人族血統。
- 母親為魔族；父親為失落皇室後裔。
- 父母因結合遭皇室追緝。
- 主角幼年時一家逃亡，遭盜賊襲擊。
- 母親引開追兵；父親帶主角逃入森林。
- 父親在魔物戰鬥後重傷，將主角放入河流。
- 正式故事於十六年後展開；主角 16 歲。
- 玩家可選男性或女性主角並自訂姓名。
- 主角形象包含銀白色頭髮與紅色眼睛。
- 世界觀包含五百年輪迴概念。

## 確認：物品與技能名稱

- 初始武器：「信念」。
- 初始技能：「天風斬」。

名稱已確認；其數值、演出、取得方式與演化仍屬 M7 後續設計。

## 規劃中：劇情分支

1. 魔族路線：顛覆既有世界秩序。
2. 皇室路線：復興失落皇室。

實際事件、選項、旗標、羈絆與結局尚未定稿。

## 確認：職業設計方向

基礎職業目前為劍士、刺客、法師、牧師、遊俠與哥布林。職業與陣營彼此獨立，未來進階職業的特殊名稱與規則仍未確認。當前數值與攻擊模式見 [COMBAT_SYSTEM.md](./COMBAT_SYSTEM.md)。
