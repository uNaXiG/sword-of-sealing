# Art Guidelines

## 已確認方向

- 日系異世界輕小說風格。
- 古典歐洲中世紀奇幻元素。
- 劍與魔法世界。
- 日系動畫人物與精緻角色立繪／劇情 CG。
- 古典奇幻風格 UI。
- 不是重裝、黑暗奇幻取向。

正式美術由獨立 AI 美術設計 Session 負責；本文件不自行新增未確認的服裝、武器造型、場景或模型規格。

## 主角形象

已確認男女主角共用特徵：

- 年齡 16 歲。
- 銀白色頭髮。
- 紅色眼睛。
- 玩家可選男性或女性主角並自訂姓名。

更精細的髮型、服裝、比例、表情與動作規格尚未在本任務定義。

## 素材一致性原則

- 男女主角各素材應保持髮色、眼色、身份辨識與整體世界觀一致。
- 立繪、對話圖、CG 與戰鬥造型須由美術流程確認互相對應。
- 同一角色的不同情緒與用途變體可使用不同構圖，但不得自行改變已確認核心特徵。
- 尚未定義格式、解析度、命名模板或匯入流程的素材規格時，先等待美術規格，不擅自建立。

## Placeholder 與正式美術

目前戰場角色是幾何 Placeholder Model：不同職業以顏色與簡單造型辨識。基礎戰鬥、資料、攻擊與動畫規則開發期間不應提前大量導入正式 3D 資產。

正式 3D 角色、武器與動畫屬 M6；M3-3 已以已確認的 Placeholder 演出完成攻擊動畫驗收。人物 CG 與立繪則由劇情／美術階段依需求整合。

美術規範變更需同步更新本文件與對應的 [ROADMAP](./ROADMAP.md)／[CHANGELOG](./CHANGELOG.md)。
